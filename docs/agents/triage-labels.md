# Rôles de triage

Les skills raisonnent en cinq rôles canoniques. Dans ce repo, le rôle est la valeur du champ `triage:` du frontmatter d'un ticket (`.scratch/<chantier>/tickets/NN-slug.md`), pas un label GitHub.

| Rôle mattpocock/skills | Valeur dans ce repo | Sens                                           |
| ---------------------- | ------------------- | ---------------------------------------------- |
| `needs-triage`         | `needs-triage`      | À évaluer par le mainteneur                    |
| `needs-info`           | `needs-info`        | En attente d'informations complémentaires (souvent une décision ou une version de pepito) |
| `ready-for-agent`      | `ready-for-agent`   | Entièrement spécifié, exécutable par un agent  |
| `ready-for-human`      | `ready-for-human`   | Implémentation humaine requise (essai sur le Mac de l'utilisateur, publication) |
| `wontfix`              | `wontfix`           | Ne sera pas traité                             |

Modifier la colonne de droite pour changer le vocabulaire.
